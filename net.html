World of differences

A real-time multiplayer game built with sockets and live synchronization

The Project

What is Differences Game?

A real-time multiplayer networking game built with a TCP/UDP client-server architecture. The server manages player connections, gameplay, and score updates while synchronizing actions across up to four concurrent players using multithreading.

Players compete in three rounds to spot differences between two similar images. Real-time synchronization ensures all clients stay updated throughout the game, with the highest score determining the winner.
