Dreamverse

Project planning for a smart sleep app and AI-powered capsule

The Idea

What is Dreamverse?

Dreamverse is a conceptual AI-driven system that combines a mobile application with a smart sleep capsule. Users can choose the type of sleep experience they want, while the capsule monitors movement and neural activity to create a more personalized, comfortable, and immersive sleeping environment.

Its development was planned using a Work Breakdown Structure, sequenced with a Gantt chart, and mapped through a network diagram to determine the critical path and turn the concept into a manageable project schedule.

Objectives

What the plan covers

  • Define the scope and requirements for linking the app with the sleep capsule
  • Break the full project into a clear Work Breakdown Structure
  • Sequence and schedule every task on a Gantt chart
  • Map task dependencies and the critical path with a network diagram
  • Define roles and responsibilities for each project phase.
