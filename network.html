High Severity Attack
The Idea

What is SQL Injection?

SQL Injection (SQLi) is a web vulnerability that lets attackers manipulate database queries. This project demonstrates the attack in a controlled lab using an intentionally vulnerable banking application.

The project demonstrates both the offensive and defensive aspects of SQL Injection, from exploiting vulnerable inputs to understanding how the attack can be detected and prevented.

A high-severity attack that can expose data or compromise a database

Offensive & Defensive Objectives

OFFENSIVE
attacker@target — bash ATTACK VECTOR

$ SELECT * FROM users WHERE user='admin' AND pass='' OR '1'='1' --'

  • Demonstrate how SQL Injection vulnerabilities can be exploited.
  • Access and modify database data using automated tools.
  • Show the real-world impact of the attack on a live target.
DEFENSIVE
query.py — reviewed MITIGATION

query = "...WHERE pass='" + input + "'"

query = "...WHERE pass=%s", (input,)

  • Understand how SQL Injection occurs at the code level.
  • Learn how to detect and prevent it before it is exploited.
  • Protect web applications and the databases behind them.
