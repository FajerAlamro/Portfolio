Darek

An interactive front-end rental marketplace

The Idea

What is Darek?

Darek is an interactive front-end property rental website built for two user roles: renters and property owners. Renters browse and book apartments, villas, and chalets, while owners list and manage their own properties from the same platform.

The site centers on dynamic property filtering, detailed property pages, and an interactive booking cart, built with a strong focus on usability, smooth navigation, and a seamless marketplace experience for both sides.

Under the Hood

Core Features

Dynamic filtering

Narrow results instantly by property type, price, and location.

Detailed property pages

Photos, amenities, and pricing laid out for a quick decision.

Interactive booking cart

Collect stays, adjust nights, and see the total before confirming.

Owner dashboard

Add, edit, or remove listings without leaving the platform.

Dual-role accounts

One platform, two distinct flows for renters and owners.

Smooth navigation

A consistent path from search all the way to a confirmed booking.
